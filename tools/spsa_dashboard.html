Tests against our bots

At set steps the tuner pauses and the averaged values (the big numbers further down) play v19 as submitted (or the bot named next to the step, such as v21), on new seeds and both sides: on the 17 tuning maps, and on 5 official maps never used for tuning. Score = (wins + half the draws) ÷ games, so 50% is even. The range is where the true score probably lies (95%): a range wholly above 50% means the tuned bot is better.

Step results

Each step plays a + copy of the bot against a − copy (every parameter nudged one way in one, the other way in the other) on every ladder map (both sides), then moves each parameter toward the copy that won. A bar shows how far the + copy won (up) or lost (down) that step: wins minus losses, divided by games. One step is mostly luck; the tuner learns from many of them.

Step results as a table

Where each parameter is heading

The blue line is the parameter's value after each step; the thin grey line is where it started. A steady drift one way means the games keep preferring that direction. The big number is the average over the second half of the steps so far: the value we would test against v19. For the two added features, "off" is inside the range: a sprint cost near 800 means no sprints, 0% feeders means no early queen feeding.
